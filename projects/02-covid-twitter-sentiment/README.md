# COVID-19 Twitter Sentiment Analysis

**Status:** Complete

## Overview
Natural-language-processing project that cleans COVID-19 tweet text, explores hashtags and word frequency, applies TextBlob sentiment analysis, creates TF-IDF features, and compares Logistic Regression with Random Forest.

## Tools
Python, NLP, TextBlob, TF-IDF, scikit-learn

## How to Run
1. Open `analysis.ipynb` in Jupyter Notebook or JupyterLab.
2. Restart the kernel.
3. Run all cells from top to bottom.

## Highlights
- Text cleaning and preprocessing.
- Exploratory analysis of words, hashtags, and tweet activity.
- Positive, neutral, and negative sentiment labeling.
- TF-IDF feature engineering.
- Logistic Regression and Random Forest comparison.
- Ethical discussion of privacy, sampling bias, misinformation, and model limitations.

The notebook expects the original COVID-19 tweets CSV used in the course project.
