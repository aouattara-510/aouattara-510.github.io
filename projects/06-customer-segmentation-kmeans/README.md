# Customer Segmentation with K-Means

**Status:** Complete

## Overview
Unsupervised-learning demonstration that creates synthetic customer behavior data, scales features, selects a cluster count with silhouette score, and summarizes the resulting segments.

## Tools
Python, Clustering, K-Means, Silhouette Score

## How to Run
1. Open `analysis.ipynb` in Jupyter Notebook or JupyterLab.
2. Restart the kernel.
3. Run all cells from top to bottom.



## Portfolio Notes
This project is included to demonstrate a specific part of the data science workflow and is documented so that a reviewer can quickly understand the objective, method, and output.
