## Publish with GitHub Pages

1. Create a new public GitHub repository, such as `portfolio`.
2. Upload all files and folders in this package to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.
6. GitHub will provide your public website URL.

## Customize

- Edit text in `index.html`.
- Change design variables at the top of `styles.css`.
- Replace the SVG previews in the `assets` folder with actual project screenshots when available.
