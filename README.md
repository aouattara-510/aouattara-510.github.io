## GitHub Pages Deployment
For a user site, the repository should be named:

`aouattara-510.github.io`

Then:
1. Upload the contents of this repository to the `main` branch.
2. Go to **Settings > Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/(root)`.
5. Save.

The public site should then be:

`https://aouattara-510.github.io/`
