# A/B Testing Simulation

**Status:** Complete

## Overview
Statistical experiment simulation comparing two conversion rates with a two-proportion z-test and confidence-oriented interpretation.

## Tools
Python, Statistics, Experimentation, A/B Testing

## How to Run
1. Open `analysis.ipynb` in Jupyter Notebook or JupyterLab.
2. Restart the kernel.
3. Run all cells from top to bottom.
