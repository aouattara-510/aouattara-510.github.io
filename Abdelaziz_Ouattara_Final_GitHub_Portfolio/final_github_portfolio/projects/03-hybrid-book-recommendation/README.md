# Hybrid Book Recommendation Demo

**Status:** Complete

## Overview
A self-contained demonstration of content-based and collaborative recommendation logic using a small synthetic book catalog and reader-rating matrix.

## Tools
Python, pandas, TF-IDF, Cosine Similarity, Recommender Systems

## How to Run
1. Open `analysis.ipynb` in Jupyter Notebook or JupyterLab.
2. Restart the kernel.
3. Run all cells from top to bottom.



## Portfolio Notes
This project is included to demonstrate a specific part of the data science workflow and is documented so that a reviewer can quickly understand the objective, method, and output.
