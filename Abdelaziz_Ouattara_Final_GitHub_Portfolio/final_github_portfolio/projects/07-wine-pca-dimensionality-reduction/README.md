# Wine PCA & Dimensionality Reduction

**Status:** Complete

## Overview
Principal component analysis on scikit-learn's wine dataset to illustrate feature scaling, variance explained, and low-dimensional representation.

## Tools
Python, PCA, Feature Scaling, Visualization

## How to Run
1. Open `analysis.ipynb` in Jupyter Notebook or JupyterLab.
2. Restart the kernel.
3. Run all cells from top to bottom.
